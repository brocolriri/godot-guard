# Godot 3.x idioms that leak into Godot 4 code (godot3_isms)

Verified 2026-09-15 against the Godot 4.7 class reference (docs.godotengine.org `stable` = 4.7), the `4.7` branch source, and the official *Upgrading from Godot 3 to Godot 4* guide. Machine-readable twin: `godot3_isms.json` (same rows). Patterns are Python `re` syntax, intended for `re.MULTILINE` over one `.gd` file. Rows tagged **hallucination** are APIs that never existed in any Godot version.

Severity: `error` = will not parse or will fail at runtime on 4.x; `warn` = valid-but-deprecated, or a pattern with false-positive risk that needs a human look.

Sources abbreviations: UP4 = https://docs.godotengine.org/en/stable/tutorials/migrating/upgrading_to_godot_4.html · RENAMES = https://github.com/godotengine/godot/blob/4.7/editor/project_upgrade/renames_map_3_to_4.cpp (official 3→4 converter map) · GDB = https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_basics.html · GDS = https://docs.godotengine.org/en/stable/classes/class_@gdscript.html · GLOBAL = https://docs.godotengine.org/en/stable/classes/class_@globalscope.html
